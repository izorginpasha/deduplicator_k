## 📚 Документация: Архитектура системы дедупликации событий

### 📌 Назначение
Система обрабатывает поток событий через Kafka, проверяя каждое событие на уникальность (в течение 7 дней) с использованием Redis и Bloom-фильтра, после чего уникальные события передаются на дальнейшую обработку (например, сохранение в БД).

---

### ⚙️ Компоненты системы

#### 1. **FastAPI-приложение (`main.py`)**
- **Роут:** `POST /event`
- **Функциональность:** Принимает событие в формате `Event`, генерирует UUID, сериализует событие и отправляет в Kafka.
- **Kafka Producer:** Инициализируется на старте приложения.
- **Зависимости:**
  - `aiokafka.AIOKafkaProducer`
  - `pydantic.BaseModel`
  - `.env` с переменной `TOPIC`

#### 2. **Kafka (брокер сообщений)**
- **Используется как очередь между API и обработчиком событий**
- **Топик:** По умолчанию `events` (настраивается через `.env`)

#### 3. **Consumer (`consumer.py`)**
- **Консьюмер Kafka:** Получает события из топика
- **Дедупликация:** Использует `Deduplicator` для определения уникальности события
- **Обработка уникального события:** Логирование или сохранение в БД
- **Грейсфул-шатдаун:** через SIGINT/SIGTERM

#### 4. **Deduplicator (`deduplicator.py`)**
- **Метод `is_duplicate(event)`**:
  - Хеширует сериализованное событие
  - Проверяет в Redis, затем в Bloom-фильтре
  - Если уникально — записывает в Redis с TTL и добавляет в Bloom
- **Метод `reset()`**:
  - Очищает Redis и пересоздаёт Bloom-фильтр
- **Использует:**
  - `pybloom-live`
  - `hashlib`
  - `redis.asyncio`

---

### 🧪 Формат события (`Event`)
```json
{
  "event_name": "string",
  "userId": "string",
  "client_id": "string",
  "event_datetime": "2024-01-01T00:00:00Z",
  "product_id": "string",
  "client_id_query": "string"
}
```

---

### 📁 ENV-переменные
```env
TOPIC=events
KAFKA_BOOTSTRAP=localhost:9092
```

---

### 📌 Примечания
- Все события проверяются по хешу сериализованных ключей: `event_name`, `userId`, `client_id`, `event_datetime`, `product_id`, `client_id_query`
- Redis TTL — 7 дней (настраивается через `ttl_seconds`)
- Bloom-фильтр: масштабируемый, малый рост
